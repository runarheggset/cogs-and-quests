# Mod licenses

Audited 2026-08-29 via the Modrinth API (plus GitHub for CurseForge-only mods).

**Why this doesn't block anything we do:** the exported pack (CurseForge format)
contains **no mod jars** — only project/file IDs; every player's launcher downloads
mods from CurseForge directly, which is exactly the distribution channel every
author has opted into. The same applies to our GitHub releases. So All Rights
Reserved / NC-licensed mods are fine to *reference*. What we must NOT do without
checking per-mod terms: bundle jars in the repo or a release, or fork/patch a mod.
